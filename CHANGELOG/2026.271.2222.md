# 2026.271.2222 — fix(opencode): async + abortable coord executors (spawnSync froze the server)

## Summary

**R1 RCA fix (opencharly/opencharly#299). Supersedes #145** (auto-closed at the
5-verdict block threshold; carried forward to this clean thread).

The byte-identical `coord.ts` here carried the same defect the merged umbrella
(`opencharly/opencharly#300`) fixed: the synchronous spawn helper blocks opencode's
server event loop for the child's whole lifetime and ignores the tool executor's
abort signal, so `coord_watch` (the long-lived `gh_watch.sh` watcher) **froze and
restarted the server**.

Both executors now use async, abortable `Bun.spawn` (mirroring `pr-watch.ts`); the
tool executor's `context.signal` is wired to a `kill()` via the signal's `abort`
event (**not** a spawn option), the kill is **SIGKILL** (the watcher's TERM trap
defers SIGTERM), and `coord_watch`'s `timeout` is enforced tool-side. `coord.ts` and
`scripts/check-opencode-coord.mjs` are **byte-identical to the merged umbrella's**
`origin/main` (a `diff` is run below).
