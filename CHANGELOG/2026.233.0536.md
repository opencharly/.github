# 2026.233.0536 — Pure event-driven auto-merge engine

The auto-merge engine now triggers on EVERY completed check run (`check_run: [completed]`)
instead of only the pr-validator.  This ensures the PR merges when ALL checks are green,
regardless of which order they complete.

Changes:
- `auto-merge-reusable.yml`: single non-looping check of ALL check runs on the PR head.
  If all green → finalize CHANGELOG, enable native auto-merge, exit.
  If not → exit — next `check_run` event re-triggers naturally.
- `tag-on-merge.yml`: new companion workflow, triggered by `pull_request: [closed]` when
  merged.  Creates CalVer release tag on merge commit.
- `auto-merge.yml` (dispatcher): trigger changed from `workflow_run` to `check_run`.
- All old polling/sleep/snooze functions removed.  Zero sleep, zero loops.

Change class: CI/workflow.
