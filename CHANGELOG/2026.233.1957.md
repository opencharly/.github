# 2026.233.1957 — Fix secrets-in-if parse error in pr-validator

`if: secrets.X != ''` is rejected by GitHub at workflow parse time
("Unrecognized named-value: 'secrets'"), which broke every dispatcher
run after the bot-token flow landed. The token steps now run
unconditionally (App step continues-on-error) and a bash guard
enforces that a token resolved.
