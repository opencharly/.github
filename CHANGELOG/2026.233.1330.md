# 2026.233.1330 — Clean auto-merge engine: native auto-merge + CHANGELOG rename

The auto-merge engine is simplified to use GitHub's native
enablePullRequestAutoMerge (which waits for ALL required checks via
branch protection) instead of reimplementing check-waiting.

Flow:
1. pr-validator passes → workflow_run triggers the engine
2. Engine renames the CHANGELOG placeholder to the merge-time CalVer
3. Dispatches a fresh validator run on the new head
4. Enables native auto-merge
5. GitHub merges when all checks pass
6. tag-on-merge creates the CalVer tag on merge

Change class: CI/workflow — engine simplification.
