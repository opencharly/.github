# 2026.234.0002 — Tag-on-merge via workflow_run
<!-- auto-merge-finalized: 2026.234.0002 -->

Neither `pull_request: closed` (merge events carry action `merged`,
an invalid trigger type) nor `push` (GITHUB_TOKEN events create no
runs) fires after a bot auto-merge. `workflow_run` on the validator's
completion is the only reliable post-merge event (the old engine
tagged distro-ubuntu merges this way). The reusable looks the PR up by
the run's head sha and tags the merge commit with its commit-date
CalVer.
