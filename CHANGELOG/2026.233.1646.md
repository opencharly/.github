# 2026.233.1646 — Fix approve workflow: check conclusion at runtime
<!-- auto-merge-finalized: 2026.233.1646 -->

The approve job's `if: github.event.workflow_run.conclusion ==
'action_required'` evaluated to false in the event payload, so the job
was skipped and GITHUB_TOKEN-created runs stayed in approval-required
state. Moving the check into the script (runtime) fixes it: the job
always runs, logs the conclusion, and only approves when it is
action_required.
