# 2026.275.0349 — docs+governance: the body-only re-run is the REST call; protect it in the claims manifest

## Summary

This repo prescribed `gh run rerun <run-id>` for the body-only fix, in `README.md` and in the `org-wide-pr-validator-required.yml` comment. Its governance manifest also **required** that text in the git-workflow skill source. But `gh run rerun` cannot re-run this org-required workflow: gh resolves a run's workflow against the **target** repo, gets a 404 because the workflow is defined here, and exits 1 without re-running. The evidence and gh-source mechanism are in opencharly/layer-charly-internals#71. The texts also claimed that a re-run updates the check run "IN PLACE (no duplicate)", which is false: a re-run is a new attempt with a new check run that supersedes the failure.

This PR changes three files:
- **`README.md`:** the body-only-fix paragraph now prescribes `gh api -X POST repos/<owner>/<repo>/actions/runs/<run-id>/rerun`, with the measured behaviour.
- **`.github/workflows/org-wide-pr-validator-required.yml`:** the same correction, **comment lines only**, so the workflow's behaviour is unchanged.
- **`scripts/governance-claims.tsv`:**
  - the skill-source `rerun_manual` row flips from `require gh run rerun` to `require actions/runs/.*/rerun`;
  - new `forbid gh run rerun <run-id>` rows protect the skill source, this `README.md` and the workflow.

The forbid pattern targets the *prescriptive* form `gh run rerun <run-id>`. The new texts mention the bare `gh run rerun` only as a "not this" warning, which the gate allows.

**Staged on purpose:** the `marketplace projection` rows (`marketplace/internals/skills/git-workflow/SKILL.md`) are unchanged here. They flip in the same change as the marketplace regeneration of layer-charly-internals#72's source. Flipping them now would fail the umbrella-root gate against the not-yet-regenerated projection.

**Landing order:** opencharly/layer-charly-internals#72 (the skill source) had to land first, and it has: merged as `1f3fcca04`. The control below shows the new skill-source rows fail against the pre-#72 source.

Relates to #156 and opencharly/layer-charly-internals#71.
