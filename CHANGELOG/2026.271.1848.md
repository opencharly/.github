# 2026.271.1848 — feat(opencode): coordination custom tools in the org dotgithub repo

## Summary

Adds the opencode harness config so agents working `opencharly/.github` (the org
dotgithub repo) have the same coordination surface as the umbrella. **ALL shared files
are BYTE-IDENTICAL to the umbrella's copies** (`opencharly/opencharly#295`); the
grammar and the scripts live ONCE in `opencharly/marketplace` (R3), and this repo
carries **NO forked copy**.

- **`.opencode/plugins/coord.ts`** — V2 custom tools `coord_comment` (verb-labelled
  comment with the canonical `Agent:`-FIRST / `Assisted-by:`-LAST footer) and
  `coord_watch` (a bounded wait).
- **`.opencode/plugins/pr-watch.ts`** — the in-process PR-event watcher (inert until
  `.opencode/pr-watch.items` carries an item).
- **`.opencode/lib/wake-line.ts`** — the ONE shared wake-line helper.
- **`scripts/check-opencode-coord.mjs`** — the A/B/B2/C gate (live-or-skip).
- **`.opencode/instructions.md`**, **`opencode.json`**, **`.opencode/package.json`**,
  **`.opencode/.gitignore`**, **`.opencode/coord.conf.example`**.

With no `marketplace` submodule here, the plugins resolve `../marketplace/scripts/…`
in the umbrella session-worktree layout (`.worktrees/<slug>/dotgithub` →
`.worktrees/<slug>/marketplace`), or via `COORD_SH` / `GH_WATCH_SH`.
