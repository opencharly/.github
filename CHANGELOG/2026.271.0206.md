# 2026.271.0206 — feat(ci): the cross-surface governance reconciliation gate (+ drop the dangling rerun-listener ref)

## Summary

**The class this closes (issue opencharly/opencharly#282).** A normative rule is stated in
two or more independently-edited surfaces — the umbrella `AGENTS.md`, `charly/AGENTS.md`,
the skill sources in their standalone candy repos, the GENERATED `marketplace` corpus, the
validator rulebook (`AI_REVIEW_PROMPT`), and the `.github` workflows/scripts. There is no
single source of truth and no reconciliation gate, so a rule added to one surface silently
collides with or drifts from the same rule in another. Measured on current `origin/main`:
the identity-footer **order** contradicted between the validator's rulebook and the
`AGENTS.md`/skill; the takeover **window** drifted (30 vs 60 min); the `.github` validator
rulebook mirror lagged the live org variable; and a `distribute-rerun-listener` reference
dangled after the rerun design changed.

**This PR lands the structural gate (the missing control) plus one surface fix.**

1. **`scripts/governance-reconcile.sh`** — the cross-surface reconciliation gate. It reads a
   committed manifest and asserts, per `(claim, surface)` row, that a canonical phrase is
   **present** and a legacy phrase is **absent**. Offline, dependency-free (`bash` +
   `coreutils`). Path resolution supports both roots: a `dotgithub/…` path resolves in the
   umbrella (`<root>/dotgithub/…`) and in a standalone `.github` checkout (`<root>/…`); a
   sibling-repo path (`layer-charly-internals/…`, `marketplace/…`, `AGENTS.md`) **SKIPS
   cleanly and visibly** when absent — never a silent pass.
2. **`scripts/governance-claims.tsv`** — the manifest: 32 rows over **seven** claims
   (footer order, the 60-min comment-first takeover window, the account-gated sign-off, the
   successor protocol, the rerun channel, the auto-close threshold), each across the umbrella
   `AGENTS.md`, the `git-workflow` skill source, the `marketplace` projection, and this repo's
   own workflows.
3. **`.github/workflows/validator-harness.yml`** — wires the gate into CI (its self-test +
   an org-wide run) beside the existing offline script tests.
4. **`.github/workflows/org-wide-pr-validator-required.yml`** — drops the dangling
   `distribute-rerun-listener` reference: that design was replaced by the org-wide `rerun.yml`
   sweep (PR #122), so the comment now names the real channel.

**Scope note (one editor per file).** This PR deliberately does **not** touch
`charly.yml` or the `AGENTS.md`/skill/marketplace prose — `charly.yml` is owned by the open
`opencharly/.github#127` (feat/governance-rca), and the `AGENTS.md` + skill + marketplace
prose are being reconciled by the coordination session. The gate's manifest is the
**coordination point**: when those land, `governance-reconcile.sh --root <umbrella>`
asserts them; until then the sibling rows are visibly skipped in this repo's CI.
