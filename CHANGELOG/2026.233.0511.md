# 2026.233.0511 — Unified auto-merge engine
<!-- auto-merge-finalized: 2026.233.0511 -->

The org-wide auto-merge engine is now a SINGLE reusable workflow
(`opencharly/.github/.github/workflows/auto-merge-reusable.yml`,
`workflow_call`) instead of a 353-line inline `run:` block copy-pasted
into every repo.

- **Proper GitHub mechanisms**: uses `actions/github-script@v7` (Octokit)
  for all API calls, `github.graphql` for native auto-merge
  enablement, and `actions.createWorkflowDispatch` for validator
  re-triggering — no raw `gh api` calls, no bash polling loops, no
  fragile re-run dance.
- **Body-append ordering fix**: the finalization note is inserted BEFORE
  the `## Attribution` section so the `Assisted-by:` footer remains
  the last line in the PR body.
- **Clean-up**: `.github/scripts/auto-merge-harness.sh` and
  `.github/scripts/auto-merge-runblock.sh` deleted — the engine has no
  de-templated copy.
- **pr-validator reusable**: the `pr-validator.yml` now supports
  `workflow_call` so it too can be called from a thin dispatcher.

Change class: CI/workflow — workflow definitions and one CHANGELOG entry.
No code, no candies, no runtime packaging.
