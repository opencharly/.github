# 2026.233.1353 — pr-validator orchestrates merge; remove separate auto-merge workflow

The pr-validator now does the whole flow on PASS:
1. AI review (pi-review-action v1.0.8)
2. Rename CHANGELOG placeholder to merge-time CalVer
3. Dispatch a fresh validator run on the new head
4. Enable GitHub's native auto-merge (waits for ALL checks)

The separate auto-merge workflow is removed — GitHub's native
auto-merge (repo setting + enablePullRequestAutoMerge) does the
actual merging.

Files:
- pr-validator.yml (reusable): review + CHANGELOG rename + auto-merge
- pr-validator-dispatcher.yml: .github repo's own dispatcher
- tag-on-merge.yml (reusable): CalVer tag on merge
- tag-on-merge-dispatcher.yml: .github repo's own dispatcher
- Deleted: auto-merge.yml, auto-merge-reusable.yml, org-wide-auto-merge-dispatcher.yml

Change class: CI/workflow — architecture simplification.
