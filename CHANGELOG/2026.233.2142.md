# 2026.233.2142 — Fix CHANGELOG rename: Contents API with the bot token

`actions/checkout` installs a GITHUB_TOKEN Authorization extraheader
(via a temp global config under an overridden HOME plus local
`includeIf.gitdir:` entries) that scoped git config cannot remove;
runner git pushes therefore counted as GITHUB_TOKEN and their
synchronize runs landed in `action_required` (proven live v1–v5). The
rename now creates the finalized file and deletes the placeholder via
the Contents API with the app token — the commits are attributed to
the app, so the resulting synchronize event runs without approval.
