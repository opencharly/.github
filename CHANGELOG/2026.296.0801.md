# 2026.296.0801 — feat(ci): the org-wide ClawSweeper advisory review, as a reusable workflow

## Summary

The org-wide ClawSweeper review, as a reusable `workflow_call` — a SECOND reviewer, advisory only. The
required gate stays `validate / validate`; this check is never a branch-protection requirement and can
never block a merge.

**Isolation.** One container of the pinned review image, against the PR's own tree mounted READ-ONLY at
`/target`. The image's entrypoint passes `--local-range`, so the engine reads
`merge-base(base, HEAD)..HEAD` and performs no GitHub reads or writes. No GitHub token enters the
container and no Docker socket is mounted. `--network bridge` gives it egress, which the remote model
endpoint requires — what it does not have is a credential, a socket, or a writable view of the PR. The
JSON verdict leaves the sandbox on stdout and THIS workflow posts it.

**The model endpoint is the org's existing one.** The key is the org secret `AI_REVIEW_API_KEY` — the
SAME secret the required gate already uses — mapped onto `OLLAMA_API_KEY`, the env var the image's
`CODEX_HOME` names. No new secret (R2).

**The caller must grant three scopes** (a called workflow's token is capped by its caller):

```yaml
permissions:
  contents: read
  pull-requests: write
  packages: read
```

**Pins.** `vars.CLAWSWEEPER_IMAGE` is the single bump point, exactly as `vars.CHARLY_VERSION` already is;
an unset variable is a LOUD failure, never a silent fallback to a rolling tag.

**Visible skip, never a mock (R8).** With no `AI_REVIEW_API_KEY` in scope the workflow posts a comment
saying the review was NOT exercised and exits 0.

## Round 1 findings — how each was closed

1. **Raw container output published without redaction.** The container's stdout AND stderr are now passed
   through a redaction pass (every non-empty secret value → `***`) BEFORE anything echoes them: the job
   log prints only the redacted excerpt, and the comment embeds only redacted text.
2. **GHCR credentials left on the persistent runner.** The login now writes into
   `${RUNNER_TEMP}/docker-config` via `DOCKER_CONFIG` — never `~/.docker` — and an `if: always()` step
   removes that directory, so nothing survives the job.
3. **The caller's required scopes were undocumented.** They are now stated in the file header and in the
   body above, with the exact block a caller needs.
4. **`if: always()` posted a misleading comment on infra failure.** The comment step is gated on
   `steps.review.outcome != 'skipped'`, so a pin/fetch failure can no longer be dressed up as "the engine
   produced no verdict".
5. **Duplicate comments past the first page.** The marker lookup uses `gh api --paginate`.

Notes also closed: the unused `head_sha` output is gone and the step is renamed to what it does (one
comment per pull request, updated in place); the body now says the IMAGE passes `--local-range` rather
than implying the workflow does, and no longer claims "nothing else is reachable"; the fetch
authenticates, so private repos work; and `pr-number` reaches the shell through `env:`, not string
interpolation.
