# 2026.233.0618 — Fix dispatcher event filter and re-dispatch loop

The auto-merge dispatcher now accepts both `pull_request` and
`workflow_dispatch` validator events, and the `fresh` gate prevents
the re-dispatch loop by only triggering on the actual finalization step.

Changes:
- `auto-merge.yml` (dispatcher): event filter widened to
  `event == 'pull_request' || event == 'workflow_dispatch'`
- `auto-merge-reusable.yml`: `fresh=true` output added to the
  fresh-finalization path (paths a/b exit early before it; only path c
  reaches it); dispatch condition changed from `stamp != ''` to
  `fresh == 'true'`
