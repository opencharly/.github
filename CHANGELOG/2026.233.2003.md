# 2026.233.2003 — Fix rename push auth: checkout extraheader overrode the bot token

`actions/checkout` installs a GITHUB_TOKEN Authorization extraheader
(`http.https://github.com/.extraheader`) that overrides URL-embedded
credentials. The rename push therefore authenticated as GITHUB_TOKEN
and its synchronize run landed in `action_required` (caught by the
acceptance test on PR #44). The push now sends the bot token
explicitly as the Authorization header.
