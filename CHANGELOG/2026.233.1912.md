# 2026.233.1912 — Bot-token rename push (fixes approval-required loop)

The rename-then-dispatch design was empirically disproven: check suites
created by `workflow_dispatch` runs are not associated with pull
requests (statusCheckRollup is null), so branch protection is never
satisfied. Likewise, GITHUB_TOKEN cannot create check-runs (Checks API
requires app auth) and commit statuses are rejected because branch
protection pins required checks to the GitHub Actions app.

The rename push now uses a bot token (GitHub App token preferred, PAT
fallback) instead of GITHUB_TOKEN. GitHub gates only runs triggered by
GITHUB_TOKEN pushes, so the resulting `pull_request: synchronize` event
