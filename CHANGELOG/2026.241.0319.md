# 2026.241.0319 — docs(tag-on-merge): warn that the dispatcher's permissions block is fail-closed

## Summary

Eight opencharly repos — `distro-arch`, `distro-cachyos`, `distro-debian`, `distro-fedora`,
`distro-ubuntu`, `pkg-arch`, `pkg-debian`, `pkg-fedora` — shipped a `tag-on-merge` dispatcher
whose `permissions:` block listed only `contents: write`. **Every `tag-on-merge` run in all eight
ended in `startup_failure`, and no merged PR in any of them produced a release tag.**

```
$ gh run list --workflow=tag-on-merge.yml --limit 3 -R opencharly/distro-arch
completed  startup_failure  tag-on-merge  main  schedule      2026-08-28T21:06:32Z
completed  startup_failure  tag-on-merge  main  workflow_run  2026-08-28T15:40:13Z
completed  startup_failure  tag-on-merge  main  workflow_run  2026-08-28T15:36:31Z
```

`distro-arch` sat 4 commits past its newest tag, `distro-cachyos` likewise — and the fixes those
commits carried were invisible to every consumer pinning by tag. That had a measured downstream
cost: `distro-cachyos` still resolves `distro-arch:v2026.236.0159`, whose refs reach a
pre-cutover charly that still carries `candy/plugin-mcp` and `candy/plugin-record`, producing four
`remote candy name conflict` errors that block `check-selkies-labwc-pod`.

## Why

The reusable workflow this dispatcher calls declares **both** scopes at job level:

```yaml
jobs:
  tag-and-changelog:
    permissions:
      contents: write
      pull-requests: read
```

A caller that sets an explicit `permissions:` block makes every scope it does **not** list `none`,
and a reusable workflow may not request more than its caller's ceiling — so the call is rejected
before any job starts.

**This template already carries the correct block.** The eight repos drifted by never being
re-synced from it, not by copying anything stale. What the template did not say is that the block
is load-bearing and **fails closed**: `startup_failure` produces no job to inspect, and surfaces
no error anywhere a merge would notice, so a repo can stop tagging silently and stay that way for
weeks — which is exactly what happened.

This PR documents that consequence for the next person who hand-trims the block.
