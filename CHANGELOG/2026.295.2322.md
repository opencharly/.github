# 2026.295.2322 — docs(ci): org-wide runner label contract and the standard fork caller

## Summary

Declares the org-wide CI-runner contract, ships the standard first-party-fork validator caller, and
moves the org's merge-time tagging onto the fleet.

- **README: the label contract, reconciled with measurement.** The fleet registers
  `opencharly-ubuntu` (selected by `vars.CI_RUNNER_LABEL`, visibility now `all`, and by the Docker
  jobs' `vars.CI_DOCKER_RUNNER_LABEL`) and `opencharly` (`vars.REVIEW_RUNNER_LABEL`, the review
  fleet). A **hosted** label is not captured: a job on `ubuntu-latest` stays on GitHub-hosted
  runners even when a self-hosted runner carries that label (measured — the fleet stayed idle).
  The variable expression is the no-edit path; a hardcoded hosted label needs a one-line edit.
- **`templates/fork-pr-validator.yml`.** A first-party fork cannot join the org ruleset — its
  required-workflow rule makes `gh repo sync` fail (`opencharly/.github#179`) — so it carries one
  small caller to the same engine.
- **`tag-on-merge.yml` now runs on the fleet** (`runs-on: ${{ vars.CI_RUNNER_LABEL || 'opencharly' }}`).
  This is a **runtime change**, not documentation: it moves every repo's merge-time tagging off
  GitHub-hosted runners. The workflow uses only GitHub Actions and bash, so the fleet needs no
  extra tooling; the `|| 'opencharly'` fallback keeps it running if the variable is ever invisible,
  and the fleet carries that label.

## Root cause / finding (R1)

1. **Org rulesets exclude forks by design** (`scripts/lib-org.sh` computes the exclude set from
   `isFork`), and while the ruleset targets a fork the `workflows` rule refuses `gh repo sync`
   (`Required workflow 'charly/pr-validator, charly/pr-validator' is not satisfied`). A fork needs a
   caller; shipping it as a reviewed template stops each fork inventing its own.
2. **A self-hosted runner carrying a hosted label receives none of those jobs** — measured: a
   dispatched CI run put every `ubuntu-latest` job on GitHub-hosted runners while the fleet idled.
3. **`CI_RUNNER_LABEL` had `visibility: private`**, so public repositories never saw it and fell
   back to a YAML default. It is now `all`, value `opencharly-ubuntu`.
