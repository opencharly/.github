# 2026.233.1151 — Fix YAML syntax error in auto-merge-reusable.yml

Line 114 had `run: echo "Skip: ${{ steps.pr.outputs.reason }}"` where
the `:` after "Skip" combined with the `{{ }}` expression syntax caused
the YAML parser to interpret the colon as a mapping separator in a flow
context. Fixed by separating the label with single quotes.

This YAML error was the root cause of all previous "check_run is
unreliable" observations — the check_run events were firing correctly,
but the reusable workflow had invalid YAML and silently failed.

Change class: CI/workflow — one-character fix in the reusable engine.
