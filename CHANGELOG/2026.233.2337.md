# 2026.233.2337 — Tag-on-merge via push events

Auto-merged PRs never fire `pull_request: closed` on this GitHub (the
merge event action is `merged`, which is not a valid workflow trigger
type), so the closed-based tag-on-merge never ran. Every squash merge
pushes a commit to main; the dispatcher now tags the pushed sha with
the merge-time CalVer.
