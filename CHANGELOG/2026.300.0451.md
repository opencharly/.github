## Summary

The org **archived** `layer-charly-internals`, its skills moved into the **umbrella's own** `.agents/skills/…` trees, and this repo's governance surfaces still pointed at the retired carrier. Three filed findings, one theme, one gate:

- **#257 — the 19 stale pointers.** `scripts/governance-claims.tsv` named **19 of its 81 rows** at `layer-charly-internals/…` and `layer-charly-internals-extra/…`. The org no longer carries those repos, so the checker **skipped every one of them**: a listed surface that cannot be reached was indistinguishable from one that was never checked. The rules those rows claim — the takeover window, the sign-off account gate, the successor protocol, the read-in-full rule, the RCA-on-validation-failure rule, the footer order, the re-run manual, the auto-close threshold, fix-or-file and the coordination vocabulary — were **unasserted org-wide**. The rows are repointed at the home that now holds the prose: the umbrella's own `.agents/skills/…` trees. The prose is unchanged; only the pointers move.
- **#250 — the unanchored surface.** One path was named by a `forbid` row **only**, and a forbid row asserts that a phrase is **absent** — vacuously true of *any* file at that path, including a file that holds no rule at all. So the table could not say *"this path IS the surface"*, and the row could never go red. The surface is now pinned by a `require` row, **and the class is made structural**: the checker now **FAILS** a manifest that names a path no `require` row pins. The verdict is about the **table**, not about the checkout, so an unanchored path fails in every root — including one that does not carry the surface at all.
- **#251 — the dead byte figure.** `scripts/strip-config-version.sh` justified its `> 1 MB` fallback with a figure that no longer exists: it cited `layer-charly-internals/charly.yml` as 1,038,418 bytes, and that repo is archived. The fallback is **kept** — it is a forward guard, and the branch is **not** dead code: `scripts/strip-config-version_test.sh` exercises it with a `> 1 MB` fixture on every run of this repo's gate — and the comment now states the threshold, what triggers it, and a **live** measurement (the org's largest `charly.yml` is `charly/charly.yml` at 316,230 bytes, measured 2026-10-27).

The prose that names the retired carrier is swept in the same phase (R5): the manifest's header, the checker's three path examples, and the two comments in `strip-config-version.sh`.
