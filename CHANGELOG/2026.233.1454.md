# 2026.233.1454 — pr-validator orchestrates merge; remove separate auto-merge workflow
<!-- auto-merge-finalized: 2026.233.1454 -->

The pr-validator now does the whole flow on PASS:
1. AI review (pi-review-action v1.0.8)
2. Rename CHANGELOG placeholder to merge-time CalVer
3. Dispatch a fresh validator run on the new head (workflow_dispatch)
4. Enable GitHub's native auto-merge (waits for ALL checks)

The separate auto-merge workflow is removed — GitHub's native
auto-merge (repo setting + enablePullRequestAutoMerge) does the
actual merging.
