# 2026.234.1439 — Use raw fetch with bot token for CHANGELOG write

## Change

- `tag-on-merge.yml`: replace the octokit per-request auth override with a
  raw `fetch` carrying the bot token. octokit in github-script is pre-authed
  with GITHUB_TOKEN, so the override was unreliable and the write went out
  as github-actions (not the App) — failing the ruleset required checks.
  Raw fetch guarantees the App/PAT identity that IS the ruleset bypass
  actor for main.
