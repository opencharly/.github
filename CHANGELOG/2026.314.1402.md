Tags every org head that carries **no tag and no CHANGELOG excuse** — the 411 heads the caller reconcile wrote before `#296` taught it to tag its own writes. **Add-only**: it creates a ref only where no tag points at the head, and never moves, deletes or re-points one.

**Round 1 also caught the semantics, and the fixes are behavioural rather than cosmetic:**

- **`api_absent()`** now separates a genuine `HTTP 404` from any other failure. Before it, an auth error, a rate limit or a network blip read as "no tag exists", so `--apply` would have created a **second tag at an already-tagged head** — the add-only guarantee this tool exists to keep.
- **The CHANGELOG excuse is the control's own rule**: a CHANGELOG tip is skipped only when its **parent** is tagged; a tip whose parent is untagged is reported and tagged (arm 7), because that is a head the control still refuses.
- **`calver_for_head()` is gone**; the backfill calls `calver_at()` in `scripts/lib-org.sh`, so the reconcile and the backfill share one per-repo derivation.

**Tier: `analysed on a live system`, not `fully tested and validated`.** The live half is the check-mode pass across the org, pasted above. The **`--apply` branch — the point of the tool — has only ever run against a mock**, so it has not run live, and claiming the top tier for it is the inflation round 1 named. The fleet run is the operation that will earn it.

**Nothing has been created by this change**: the tool has only ever run in check mode, and `--apply` is a separate operation to be piloted on a named few and read back before the fleet — exactly as the reconcile's own rollout was.
