# 2026.234.1340 — Decouple tag creation from CHANGELOG creation

## Change

- `tag-on-merge.yml`: the tag-exists check previously `return`ed early,
  skipping CHANGELOG creation entirely for any PR whose tag was created
  in an earlier run. Tag and CHANGELOG are now independent idempotent
  operations: each is created if missing, so a failed CHANGELOG write is
  retried by the next sweep without being blocked by an existing tag.
